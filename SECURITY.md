# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.x     | ✅        |
| 2.x     | ❌        |
| 1.x     | ❌        |

## Reporting a Vulnerability

Do **not** open a public issue, pull request or discussion for security problems.

Report privately to **info@13node.com** with:

- A description of the vulnerability and its impact
- Steps to reproduce (or a proof of concept)
- Affected package version, PHP, Laravel and Filament versions

You will get an acknowledgement within 5 business days. Once confirmed, a fix
is released and the issue disclosed publicly with credit to the reporter,
unless you prefer to stay anonymous.
